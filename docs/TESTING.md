## 추가 오류·접근성 검증

- 최초 실행에만 예시가 저장되고 두 번째 읽기에는 저장을 반복하지 않음
- 깨진 JSON, 잘못된 스키마, 중복 ID, 잘못된 수업 데이터 처리
- 손상된 원본을 자동 덮어쓰지 않고 안내 표시, 새 수업 저장으로 복구
- 저장 용량·권한 오류 시 기존 저장 데이터와 폼 입력 보존
- localStorage 읽기 자체가 차단되어도 앱과 세 화면이 중단되지 않음
- HTML 형태의 수업명이 텍스트로 표시되며 실행되지 않음
- 본문 바로가기, Enter로 요일 선택·수업 추가 진입, Tab 이동·라디오 방향키 조작
- 390px·1440px 각각의 세 화면에 axe WCAG 2 A/AA 및 2.1 A/AA 자동 검사 적용: 위반 0건
- 외부 출처 요청 없음, 주요 세 화면 이동 중 JavaScript 런타임 오류 없음
- Chrome에서 `file://`로 index.html 직접 실행 후 수업 추가·새로 고침 저장 확인

## 발견한 문제와 수정

- 본문 바로가기의 해시가 앱 라우터로 전달되는 문제를 수정해 화면을 바꾸지 않고 본문에 포커스하도록 처리했습니다.
- 밝은 보조 문구와 경고 카드의 텍스트 대비를 보완했습니다.
- 요일 버튼·서비스 홈 링크의 표시 문구와 접근 가능한 이름이 일치하도록 수정했습니다.
- 비동기 해시 전환이 끝나기 전에 검사하던 테스트는 화면·요일 선택 상태를 기다리도록 보완했습니다.

수정 후 전체 브라우저 테스트를 하위 경로에서 다시 실행해 20개 모두 통과했습니다.
